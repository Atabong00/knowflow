HOTP MUST BE IMPLEMENTED AND VERIFIED BY KEYCLOAK.

The application MUST NOT independently verify HOTP.

The application MUST NOT store:

* HOTP secret
* HOTP counter

* OTP verification state
* OTP verification result

The application must never decide:

```text

```

The application should only receive the successful OIDC authentication result from Keycloak.

# 9. HOTP POLICY

Configure the Keycloak OTP Policy specifically for HOTP.

Use:

```text
OTP Type: HOTP / Counter-based
```

Do NOT configure TOTP.

The system must not depend on server time for HOTP verification.

Configure:

```text
Algorithm: SHA-1 unless the installed Keycloak/Authenticator compatibility requires SHA-256
Digits: 6
Initial Counter: 0
Look-Ahead Window: conservative value such as 1
Reusable Code: disabled
```

Do not arbitrarily change these values without checking compatibility with the authenticator application.

Most importantly:

```text
HOTP = counter based
NOT time based
```

The Keycloak HOTP counter must be authoritative.

Keycloak increments the HOTP counter after successful OTP authentication.

# 19. COUNTER SYNCHRONIZATION



Do not implement custom counter logic inside the application.
